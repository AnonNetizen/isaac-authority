# 未修改旧模组实验

`legacy_chaos` 是独立的测试模组，尚未安装到游戏。它刻意在更新回调中使用本地随机数、时间，在渲染回调中修改金币，并将语言、界面位置和自定义按键保存在私有变量和模组数据中。真实游戏安装测试必须使用一次性存档和种子局；当前自动测试只在 Lua 5.3 模拟 API 环境中加载原始代码。

原始采集测试证明三个局部方案不足：重复执行渲染会重复改变世界；两台各自运行随机数和时间会得到不同结果；重放主机文字不能自动生成客机另一种语言。它不证明完整的引擎隔离或虚拟机隔离永远无法实现。原生观察器的客机模拟仍运行，这个模组不能作为联机兼容成功的证据。

2026-10-10 新增的主机侧影子 Lua 模型用同一份原始 `legacy_chaos` 代码生成两套个人界面，只提交主环境的金币修改。它需要匹配世界 API 调用，并从接受的历史重建私有变量。详见 [隔离实验](../docs/ISOLATION.md)。

`config_drives_world` 是新的失败反例：个人设置直接影响渲染中的世界写入。两个上下文产生不同写入时，模型必须拒绝整个候选帧并恢复世界、配置与私有变量。拒绝通过不表示模组兼容通过。它也不自动安装到游戏。
