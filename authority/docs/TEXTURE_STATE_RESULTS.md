# 图层图片选择与图像加载结果

本轮完成独立 Windows x86 命令行候选 `--texture-suite`，ABI `ia-lua533-texture-state-1`。45 项新分类检查完整运行两次，普通计算、配置、世界结果、步骤和精灵状态一致；上一候选的 41 项清单原样回归通过。真实 MCM/EID 初始化仍未通过，绘制、菜单导航、用途投影和联机仍未通过。旧模组源码、个人配置文件与存档未改，没有启动或附加游戏。

## 已实现的状态

从冻结 ANM2 提取 7 个精灵、26 个图层和 19 个 PNG 的对应关系，保存实际图片尺寸、内容哈希和提供者证明。相同图片被多个图层共用时，每个图层分别记录选择。路径大小写和斜杠归一化后绑定同一冻结资源，命令仍保留原始路径。

ReplaceSpritesheet 更新选中图片，LoadGraphics 验证资源后记录当时完整图层映射；已加载图片在 LoadGraphics 前保持原状态。Load 的 graphics 参数、重新加载时的状态重置、反复替换、缓存方法和对象回收都受测。所有操作保留先后顺序，继续使用每精灵 128 条、每上下文 1 MiB 的操作记录限制；尚未实现长期 HUD 帧发布和引用释放。

接口依据为 [Sprite API](https://wofsauge.github.io/IsaacDocs/rep/Sprite.html#replacespritesheet) 和已有 J460 原生控制记录。文档中的 Repentance+ 替换返回值按选中图片的冻结身份是否变化计算，重复选中同一图片返回 false。历史 J460 控制只证明调用链、缓存方法和两个上下文可执行，没有读取这个返回值或比较像素。**返回值及最终画面的当前 J460 等价仍未验证**；与原版 Lua 使用同一后端对照，只能验证后端不会改变普通 Lua 计算，不能补足原生证据。

散装 PNG 在第一次使用时读取和哈希，保持禁止写入与替换的句柄；打包 PNG 使用已验证包头、索引和有界成员范围。所需元数据在内存中解码核对，不复制资源或重新哈希整个大档案。资源错误时不提交替换或加载命令。19 个资源的有限缓存随会话释放，不随调用次数新增。

## 分类与恢复

按案例实际用途统计为 27 项功能/恢复检查和 18 项预期拒绝检查。原清单部分拒绝案例沿用通用 kind 字段，封存统计依据明确的案例身份与断言，不把它们当作功能兼容。

功能检查覆盖按图层独立修改、已选与已加载状态、顺序、重复返回值、别名、缓存方法、个人配置及位置、主机金币、保存重载、已接受历史重建和 GC。分别在保存、图片替换、图像加载和文本入队后注入错误，核对配置、图片状态、版本与绘制恢复。未知资源、错误哈希/大小、错误图层、未知存储、覆盖缺失、签名、外来对象及操作上限按预期拒绝；拒绝的复现不计为兼容。

本轮没有新增网络重传或网络帧去重实现，也未用该组测试声称完成这些功能。个人 HUD 中按用途选择权威视图仍未在本候选开启，报告中的 automatic_projection_implemented 和 personal_draws_publishable 均为 false。

两个最终新清单批次分别约 18.53 秒和 17.59 秒，包含每项一次独立原版 Lua、两次研究 Lua及保护审计。原生运行最高约 0.079 秒，外部监督含启动最高约 0.196 秒，已完成模型最高 128,278 工作单位、私有提交最高约 5.93 MiB。继续保持 1000 万工作单位、5 秒子进程限时和 1 GiB 配额，未启用全量追踪。

## 真实源码尝试

| 入口 | 首个失败 | 证据 |
|---|---|---|
| MCM 中文版 | `modconfig.lua:528` 的 `Font()` | 字体构造尚未接入 |
| EID | 字符串回调注册被整数接口拒绝 | `features/eid_bagofcrafting_search.lua:58`，事件 `EIDCallbacks.SEARCH_NAME_CONVERSION` |
| MCM → EID | 同一 MCM 字体入口 | 尚未执行 EID；另有 EID 独立尝试 |

EID 已通过最初的 ReplaceSpritesheet/LoadGraphics，执行 114 个源码单元；研究运行约 0.587 秒、1,072,133 工作单位后失败。验证了 321,063 字节的打包范围和 136,685 字节的散装图片，没有超预算。这只是到首个失败入口的工作量，**不是 EID 完整初始化总量**。

最初错误只有 Expected integer，已保留对应二进制、源码和失败结果，再加入一次性的有界现场记录：最多 6 个参数、每段文本 128 字节和 8 层调用帧，以原始字节编码保存源名称；不执行 tostring，也不遍历任意表或 userdata。证据确认传入的是字符串事件，而非层号。新增拒绝案例验证现场不会被后续错误覆盖。该记录计入预算；已耗尽预算时不保证还有诊断记录空间。

下一步需要统一扩展 SDK 的字符串回调契约，并接入真实字体数据和接口；不能仅为这个 EID 事件设置特殊规则。

首版封存校验遗漏原版 Lua 在源码名称中使用 Windows 反斜杠，错误地只比较正斜杠。已保存校验失败草稿和脚本，修正为归一化路径后核对同一文件的第 58 行；源码名称原始字节、功能结果和二进制均未修改。

## 复现与保留

```powershell
python -B authority/tools/verify_texture_state.py
python -B authority/tools/run_texture_state.py run --output authority/reports/texture-check-local
```

首条只读检查二进制、源码、压缩结果、旧封存，以及小范围资源和内存中重建的元数据。第二条会创建新的结果目录，目录已存在时拒绝覆盖；日常复查优先使用首条。版本入口为 `research/texture_state_candidate_v1.json`，当前冻结清单为 `research/texture_state_v2.json`。真实尝试保留为失败，不能作为绿色功能验收。

报告直接压缩，历史初版仅保留独有失败二进制与来源快照，未制作重复 ZIP 或解压副本。自动审批拒绝了本轮编译中间文件清理，只返回 blocked by policy，未提供具体原因；缓存暂时保留，删除没有执行。源码、EXE、最终 PDB 和生成文件均保留。
