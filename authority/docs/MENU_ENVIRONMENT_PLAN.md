# 真实菜单环境：CLI 分步接入

目标仍是旧模组不逐个修改、个人设置独立、世界和奖励由主机决定。该候选独立于已封存的 UI flow，ABI 为 `ia-lua533-menu-environment-1`，只提供命令行研究入口。禁止把初始化、闭合菜单回调或拒绝诊断计为完整菜单通过。

1. 接通明确的个人按键/控制器/鼠标快照、音效命令、两名玩家与房间只读快照。完整场景包含可被 EID 描述的道具，不以空实体列表跳过 HUD。
2. 验证精确读集合、A→B→A、缓存方法、生命周期、配置保存/重载、重复帧和失败重建。每个子进程保持 1000 万工作单位、5 秒和 1 GiB；音效不调用真实后端。
3. 使用原始文件运行完整回调，以内容和实际菜单状态验收。检查历史冻结源是否带实验补丁；原有源和报告继续保留，以新的基线单独记录恢复，不修改安装目录。
4. 读查询通过后，处理真实菜单的混合世界写入，并捕获完整的精灵有序操作程序。未知入口明确拒绝；不得通过改设置、让双人场景变单人、删除回调、吞掉绘制或修改模组绕过。
5. 菜单、HUD、配置和世界隔离全部通过后，再安排一次集中的 J460 绘制重放。该候选不证明原生模拟、通信、重连、解锁或双机验收。

帧编号配合角色、事件和阶段去重。128 条/4 MiB 回执缓存带高水位，已淘汰的旧帧拒绝执行。保存和绘制失败后，通过新建上下文重放已接受历史恢复；重建计入同一预算。研究历史仍随接受帧增长，不能据固定回执容量声称整个长期会话已实现有界存储。
