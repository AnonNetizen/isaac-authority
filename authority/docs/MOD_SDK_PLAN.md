# 多模组与冻结枚举接入

沿用已封存对象候选，新增独立 SDK 候选和 ABI，不改变旧模式、原模组或存档。保持 1000 万工作上限、5 秒超时和 1 GiB 配额。

1. 校验冻结 `resources/scripts/main.lua` 和完整 `enums.lua`。执行 main.lua 原始第 1–28 行的注册包装函数，并记录全文件及片段哈希；其余引擎兼容函数仍未接入，不宣称完整引擎引导成功。
2. 注册身份以实际 Lua 表及所属上下文为依据，来源目录由冻结调用栈确定。可修改的 Name 不能改变身份或存储归属。每个来源目录、存档槽及玩家上下文分别保存原始数据；同目录辅助引用共享该目录数据。
3. 保存、删除、读取接到独立版本；消费者仅校验实际读取的目录和数据用途。回调按所属注册表移除，不能误删其他引用的同一函数；支持优先级和明确的过滤参数。失败经检查点及历史恢复。
4. 完整执行未经修改的 enums.lua。提供受控 BitSet128 值及枚举常量命名空间，未知操作报错。用原版 Lua 对照、别名/高位/错误及跨上下文测试核对，不能用空表或随意枚举值绕过失败。
5. 先短测注册、独立数据、回调、恢复、来源和资源上限，再回归旧模式和复测真实 MCM/EID/组合。完整初始化或原生世界等价未完成时保持明确失败。只保留必要代码、冻结清单及压缩结果，不复制游戏资源。
