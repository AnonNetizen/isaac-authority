# 2026-10-16 无资源配额执行测量

本轮按用户要求，用独立 Windows x86 测量程序取消执行工作量、5 秒超时、1 GiB 私有提交配额，以及消费者、字段、键、观察记录、绘制和函数栈快照的研究容量上限。正式 `ia-lua533-bound-values-1` 的 1000 万/5 秒验收及原文件保持不变；没有启动游戏、修改冻结模组或个人存档、重新使用旧全量追踪。

结论：这个样本没有出现历史记录持续驻留的问题，**可选的逐值观察仍有严重 CPU 开销**。真实 MCM/EID 入口被当前模型尚未接入的 API/加载器阻断，未获得完整初始化总量。

## 方法和边界

独立 ABI 为 `ia-lua533-bound-measure-1`，复用修复后的同一份 Lua 静态库。改变只发生在 `build-bound-measurement/source` 的派生文件；逐文件来源与哈希在 `derivation.json`。4096 桶捕获单元哈希索引保留，其链表没有容量上限；32 个栈槽数组改成实际栈数量的动态快照。长键写入的版本更新也同步开放，避免只允许读长键却遗漏后续写入。

测量子进程没有人为工作、时间、记录容量或内存配额。仍受 Windows x86 地址空间、物理内存、原版 Lua 表示范围及 uint64 计数范围约束。保留未知操作、来源歧义、权威写入权限、源码哈希和数据类型检查。没有取消这些语义检查或制造 API 返回值；没有运行刻意不终止的负例。

本轮只测原生执行和捕获，未运行表达式分析/独立值验证器，未证明个人设置/普通 HUD 用途投影、主机奖励显示或任意旧模组兼容。旧模组不改、个人配置独立、奖励跟随主机仍是待完成的整体目标。

## 实测

21 项当前模型案例与 5 项有限压力工作负载均执行结束。除原容量拒绝案例开放后应成功的情况外，其余 20 项世界、私有存储与绘制结果和已封存模型结果一致。这里的“执行结束”不把原来未解析的分支、循环或调用摘要计作功能兼容。

| 压力场景 | 原生执行工作量 | 原生秒数 | 私有提交峰值 MiB |
|---|---:|---:|---:|
| 一百万次 `cfg.amount` 读取，启用值观察 | 23,000,452 | 50.0206 | 1.57 |
| 同一源码，仅关闭可选值观察 | 14,000,369 | 0.4705 | 见完整报告 |
| 20,000 字段读取 | 620,375 | 0.8523 | 8.71 |
| 8192 字节键的 A→B→A | 3,352 | 0.0061 | 1.96 |
| 40 层递归调用 | 3,131 | 0.0058 | 1.64 |
| 257 次绘制捕获 | 11,635 | 0.0492 | 5.88 |

百万次读取实际触发 3,000,006 次各类读取事件；累计创建 1,000,008 条短命观察记录，结束保留 9 条、约 2005 字节序列化负载。采样私有提交约 1.3–1.6 MiB。它没有证明所有工作负载或长时间会话总内存固定。

同源码对照的普通结果完全一致，启用值观察的原生时间约为关闭时的 106.3 倍。这是一组顺序测量，未作统计重复或逐函数 CPU 采样；它将主要差异定位到可选观察层，不能精确分配 JSON、映射、分配器等各自占比。当前观察层每次读取仍构造 JSON 值/记录、比较，变化的 upvalue 还会序列化和分配短命记录。下一轮应优先消除这些热路径工作，不能靠放宽预算解决。工作计数只多约 1.64 倍，而耗时多约 106 倍，再次说明工作单位不等于 CPU 指令或毫秒。

原版限制对照中，百万次读取在 5 秒被终止，其他压力分别被消费者条目、长键、活跃栈或绘制位置上限拒绝。原容量案例开放后保存并绘制两条完整 65536 字节文本，活跃观察序列化负载为 264161 字节，确实越过原 256 KiB 上限。没有因此修改正式验收结论。

## 真实源码入口

使用既有冻结清单的原始 main.lua，并校验全部冻结模块文件。保持实际最小模型后端，没有切换回旧全量追踪框架或伪装完整游戏 SDK。

| 尝试 | 停止原因 | 已执行工作量 |
|---|---|---:|
| MCM | 未登记模块加载：`scripts.filepathhelper` | 197 |
| EID | 原文件第 8 行调用未接入的 `Game()` | 1,505 |
| MCM → EID 组合 | 在第一个 MCM 入口停止，EID 未到达；EID 另行独立尝试 | 197 |

这些是完整初始化的失败入口，不是所需总预算，也不能外推完整加载会有多快。真实模块加载、游戏查询和对象桥必须先接到新架构，才能测量真实 MCM/EID 的完整成本。先前旧框架能初始化的记录不能替代此处的新架构验收。
