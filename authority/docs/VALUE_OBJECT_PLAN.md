# Vector/Color/KColor 的接入顺序

从已封存 SDK 候选派生独立原型，不改旧模式和冻结模组。保持 1000 万、5 秒和 1 GiB 上限。

1. 校验 J460 引擎 main.lua 中原始常量段与 Color/Vector 包装段，原样执行。区分公开 API 契约、有限 binary32 数值模型及尚未做的原生核对。
2. 增加有上下文代次、编号及字段版本的 userdata。字段值内联，侧面只保留活跃版本；弱引用索引及地址代次防止 __gc 被覆盖或地址复用后留下有效记录。缓存方法重新校验接收者。
3. 读取只登记所读字段；同字段 A→B→A 失效，无关字段保持有效。有限数值与参数检查在写入前完成。失败沿已接受历史恢复；原本关闭的投影、菜单与绘制发布仍关闭。
4. 用未修改 Lua 对照、独立 binary32 字节样本、别名/upvalue/缓存方法、GC 和失败恢复短测验证。未知对象方法和未核实运算明确拒绝。
5. 复测真实 MCM/EID/组合，保留首个失败入口。回归旧 SDK 和旧模式，清理本次编译缓存，保留必要源码、清单、压缩报告及唯一失败记录。
