# 有界追踪候选

只用于 Windows x86 命令行研究，ABI `ia-lua533-slice3-ui-bounded-1`，模式 `ui-bounded`。原 Slice3 UI 1、Slice3 及更早运行时、清单和研究包保持原样。

构建：

```powershell
pwsh -NoProfile -File tools/build.ps1 -BuildDirectory build-ui-bounded -RuntimeOutputDirectory build-ui-bounded-release/Release -TraceResearch -BoundedUiResearch -SkipTests
```

冻结清单为 `research/ui_bounded_suite_v4.json`，沿用原真实源码与契约预期，新增大函数、普通返回值、字节串、表/闭包、循环/尾调用、缓存函数、动态加载、错误/nil/false、结构拒绝、无出口拒绝、解析与执行工作拒绝及 pcall 不能恢复耗尽上下文的案例。v1/v2/v3 和历史异常输出保留为开发记录。通用迭代额外核对 TFORCALL 与 TFORLOOP 分别执行四次：框架 describe() 的空表查询一次，用户迭代三次。补齐 Lua 合并分发的控制依赖和计费；v3 预期遗漏了框架查询，原文件保留。

```powershell
python tools/run_bounded_ui.py --binary build-ui-bounded-release/Release --game 'E:\SteamLibrary\steamapps\common\The Binding of Isaac Rebirth' --output reports/ui-bounded-final --history
```

逐例原始报告、全量重复证据比较、功能输出比较、分类成本和首个不支持入口分别记录。命令行成功返回表示报告完整，不能代替功能门槛通过。普通 Lua 不具有研究预算，因此结构/预算安全拒绝仅对候选判定；兼容案例拒绝仍算失败。

基本块 CFG 为线性存储，合流点由反向 CFG 的直接后支配树计算。内部指令的合流点为下一指令，块末为树中的后支配块起点。SETLIST/LOADKX 的 EXTRAARG 与 TEST/JMP 的跳过行为显式处理。所有块必须存在到出口的路径；不终止路径不被当成已证明的合流，实际运行仍受预算约束。结构上限为 4,096 个基本块和一个出口；不再分配旧的逐指令平方集合。

统一计费包含来源读取的 64 字节块、词法 token、编译发射、CFG 存储/解码/扫描/树链求交、两层分析结果消费、循环与静态分支扫描、执行指令、值节点与依赖边、来源集合合并、依赖传播及投影查询。私有上下文终身共用 2,000,000 单位，不会由初始化结束或帧开始重置；这比未来的逐帧账本更严格，目前只供初始化门槛研究。原型、值节点、对象、静态区域、路径和未解析条件的其他上限保留。计费不是完整 CPU 指令计数；原生函数内部及输出序列化还依赖登记契约和尺寸上限。

预算失败锁存首次错误。后续 Lua 指令和新的解析均拒绝，即使模组使用 pcall。返回错误所需的内部 C API 清理不再修改追踪元数据；该上下文已不可接受，清理不能变成继续执行。这不是事务回滚：本轮没有证明真实 UI 跨帧恢复，只验证拒绝、隔离上下文销毁和主调用栈恢复。报告逐案例写出，避免 x86 进程同时保留多份大值图。

开发验证已证明冻结 J460 主函数 12,440 条指令可表示为一个基本块。真实 MCM/EID 下一阻塞是全量依赖标记的反复遍历，预算保留，不把拒绝算作兼容。因此绘制捕获、可信真实菜单用途、导航和配置重载仍未实施。

下一步研究：按表字段及 upvalue 版本建立依赖传播的增量索引；同一对象身份可有多个别名，写入和原生副作用必须使受影响的索引失效；循环引用、闭包捕获和动态加载不能遗漏。与当前全量遍历对照每个来源结果，然后在原预算下重跑真实源码。不得仅因对象曾访问过就跳过，也不得把未知副作用视为无修改。

Lua 的表迭代顺序会影响动态图编号和耗尽位置。报告分别比较功能结果与完整证据；若完整证据不一致，就如实保留差异，不以删除来源/证明字段制造一致。完成真实初始化和可复现证据门槛后才继续绘制和菜单。

用途规则仍为 `personal-settings-authority-hud-v1`：旧模组源码不变，个人配置独立，世界贡献与有关 HUD 跟随主机。本候选不证明真实菜单和联机已经支持该规则。资源图片和字体只作为本地哈希依赖，研究包不分发游戏资源。本轮不启动或附加游戏，不操作个人存档。
