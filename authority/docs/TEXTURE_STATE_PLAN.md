# 图片替换与图像加载的命令行候选

沿用旧模组源码、独立配置和主机提交世界修改的要求。新增独立 `--texture-suite` / `ia-lua533-texture-state-1`，保留精灵候选封存；不启动游戏。正式限制继续为 1000 万工作单位、5 秒子进程和 1 GiB 进程私有配额。

1. 从已有冻结 ANM2、PNG 依赖和打包成员建立图层到图片的映射，保留图片尺寸、内容 SHA 与有界读取证明。不复制图片或完整档案，不重新全量哈希大档案。
2. 接入 ReplaceSpritesheet 和 LoadGraphics，区分已选择的图片与已加载的图片，并将顺序和资源身份写入精灵命令。成功校验资源后才提交。缓存函数、共用图片的独立图层、重复替换、重新 Load、个人上下文、回收均需验证。
3. 原版 Lua 与研究 Lua 使用相同后端，分别检查普通结果和完整状态；注入保存、状态、命令后失败，检查恢复。回归上一候选的 41 项；再尝试 MCM、EID 和组合的真实冻结源码，报告首个不支持入口。
4. 压缩报告并只读校验；删除本轮可生成的编译中间文件。未通过的真实初始化与画面不得计为通过。

接口依据为 [Sprite 文档](https://wofsauge.github.io/IsaacDocs/rep/Sprite.html#replacespritesheet) 与已有 `runs/packed-resources-j460-20261010-final/mod-runtime.json`。文档说明 Repentance+ 返回是否成功变更指定图层，之后调用 LoadGraphics。模型按冻结路径身份计算该返回值；历史 J460 测试未读取返回值，未证明当前 J460 的返回及像素等价，须在后续集中实测时补齐。图片尺寸与原字节哈希只用于资源身份和复现，不表示已经渲染。
