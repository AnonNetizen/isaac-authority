# 真实 MCM 设置调用身份：命令行验收

2026-10-17。独立 Windows x86 候选 `ia-lua533-trusted-settings-1`，继承已封存的命令捕获候选；没有替换游戏 DLL、启动游戏或写入个人存档。

本轮通过的是实际设置调用身份和普通执行行为保真。它是菜单个人值选择的前置条件，**尚未实现跨上下文个人返回值转发、返回值用途向最终绘制的完整传播或配置重载侧车**。不代表真实菜单隔离、EID 完整界面或联机修复可用。

## 本轮实现及证据

原样加载冻结 MCM。实际 `AddSetting` 返回原表时，为该表登记上下文内的弱引用身份。只在已核对的框架源文件、函数字节码、消费指令、接收设置表和当前实际回调函数同时吻合时记录设置入口。行号只作诊断；同名函数、相同路径后缀及单独调用同一回调都不能取得设置入口身份。

框架源 SHA256 为 `19a0366d7db6faae98a94dd46c5111f5ec4e5d4dc1bc456cb7fd3cacac3ffaf2`。`research/trusted_settings/profile-v2.json` 固定三份函数原型、11 个设置调用点及 47 个框架绘制候选指令。后者包含同一源码行中的其他调用，只有实际原生绘制命中才附加诊断，不授予设置用途。目录证明包含未修改 Lua 和私有 Lua 的原始 dump；剥离调试信息后的字节码一致。实际执行源码与已冻结的每条指令、upvalue 或局部变量接收位置均由校验器重新核对。

设置入口保留实际返回个数、false、nil、字符串原始字节、实际回调身份及尾调用信息。表返回目前只记录类型；原表照常由 Lua 消费，没有把它伪造为可跨上下文传输的标量。捕获中的直接嵌套绘制可以记录活动调用身份；回调返回后的框架文字绘制只记为框架绘制，不把整个 PostRender 视为设置菜单。

元数据反射暂时隔离消费者读取记录，结束时恢复。栈辅助操作使用可重定位的偏移，显式预留临时栈，并恢复原 top 和帧栈限。实际回调异常被 pcall 捕获后，如果设置栈帧已经展开而未完成，则拒绝整帧；不允许残留上下文作用于后续 HUD。

这些设置 ID 和函数 ID 仅在各自私有上下文内有效，不能直接当作主客匹配或网络实体编号。源码/原型身份证明也不等于世界操作的语义匹配证据。

## 复现

在 `D:\Coding\ISAAC` 执行完整性校验：

```powershell
python -B authority/tools/verify_trusted_settings.py
```

短测入口使用一个新的、小型报告目录；已经存在的报告目录不会被覆盖：

```powershell
python -B authority/tools/check_trusted_settings.py run --output authority/reports/trusted-settings-recheck
python -B authority/tools/check_trusted_settings.py stack-probe --output authority/reports/trusted-settings-stack-recheck
python -B authority/tools/check_trusted_settings.py real --output authority/reports/trusted-settings-real-recheck
```

原生入口为 `authority/build-trusted-settings/Release/authority-trusted-settings.exe --trusted-settings-suite <authority绝对目录> <冻结清单绝对路径> <案例ID> boundary`。参考入口使用相邻的 `authority-trusted-settings-reference.exe`，末参数为 `reference`。必须由现有有界运行器执行；这里没有游戏附加入口。

## 历史失败与仍未完成的工作

`trusted-settings-audit-v1` 清单误用了缺少物理虚拟文件的测试根，冻结加载器在初始化前拒绝；`audit-v2` 运行成功，但比较器尚未规范化已登记源路径、也未从 semantic.draws 排除新审计字段，因此对照失败。原报告保留。v3、v4 的已通过报告同样保留；v5 为栈预留修正后的最终运行。历史报告记录各次二进制哈希，未把旧记录改成新结果。

当前候选不能决定呈现上下文中某个返回值应该读取个人值还是游戏视图，也没有对返回后的字符串、表元素及相关显示分支授予可信个人用途。仅在回调返回时替换一个数字仍可能让回调内部保存或世界副作用走错路径，因此没有采用这一捷径。下一步应建立个人设置结果与呈现消费的对应关系，同时验证回调内部副作用及配置保存；对无法证明的路径继续明确拒绝。

EID 空图片替换和字节 07 的字体宽度仍是已知真实界面失败。本轮没有声称修复，也没有重跑这些未改代码的拒绝来增加通过数量。完整菜单配置重载、原生绘制画面、长会话历史回收、游戏模拟接管、通信、个人解锁和双机验收仍未完成。

对象注册及原型审计都有固定容量；当前注册弱值的元数据索引尚未做长期退役。容量耗尽会明确拒绝，不能把这种有限容量保护当作长会话支持。整个研究 Session 的接受历史仍会增长，后续需要检查点与回收。

未创建 ZIP、解压目录或游戏资源副本。冻结的新测试源和压缩报告只用于对应反例、原型与验收；游戏图片和字体继续作为受校验的本地只读依赖。历史研究包、失败记录和封存祖先未修改。
