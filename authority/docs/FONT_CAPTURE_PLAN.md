# 字体命令捕获：实现顺序

目标仍为可实际运行的主机权威联机扩展。本步补齐真实 MCM/EID 接口链中的字体捕获入口，不把命令行通过视为菜单、像素重放或联机验收。

1. 核对并冻结 J460 原始 Font 包装 304–351 行，以及已有原生观察记录中的 FontRenderSettings 值。构造器默认对齐尚无独立证据，保持未知；旧包装显式设置对齐，能够继续执行。
2. 新增独立私有运行时和受控 FontRenderSettings userdata，使用字段版本、代次和 GC 回收。旧字体度量候选原样保留。
3. 在原生签名入口验证资源并捕获一次；保留原始文字字节、二进制32浮点参数、颜色、六个设置值和对象状态版本。复制命令内容，禁止保留内存指针或回读后来修改的对象。原有文本命令共用有序队列，固定每帧容量。
4. 验证别名、缓存函数、字段失效、独立上下文、保存和失败恢复；回归原字体与回调清单。使用冻结的真实 EID `renderString` 函数验证捕获；真实完整 HUD 或菜单因未支持入口失败时如实保留。
5. 所有子进程保持 1000 万工作单位、5 秒、1 GiB 私有内存；没有全量追踪、自动扩大预算、启动游戏或修改安装目录配置。报告直接压缩，不复制资源或创建解压副本。

已查阅的 API 名称及签名说明见 [FontRenderSettings 文档](https://wofsauge.github.io/IsaacDocs/rep/FontRenderSettings.html) 和 [Font 文档](https://wofsauge.github.io/IsaacDocs/rep/Font.html)。执行依据是本机冻结源码和已有原生观察；未知默认值、布局行为及原生像素等价性不从文档推定。
