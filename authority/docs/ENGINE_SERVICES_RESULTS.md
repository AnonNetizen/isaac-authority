本阶段的 32 项分类检查和 310 项旧模式分类回归达到各自预期。包含安全拒绝和恢复案例，**不是 342 项模组功能兼容通过**。真实 MCM/EID 仍未完成初始化；菜单导航、实际绘制、奖励用途投影及联机目标仍未通过。

`Isaac.DebugString` 捕获原始消息字节、模组目录、主客身份和执行阶段，进入个人研究日志。没有写入游戏的 log.txt，也没有把日志调用替换成空操作。记录上限 128 条，总空间按包含十六进制展开及 JSON 转义的保守额度限制为 64 KiB，分配消息副本前计费和检查。工作量统计包含这项成本。

已登记单条消息最多 10,219 字节。较长消息和嵌入 NUL 明确拒绝；没有声称模拟完整原生截断和 C 字符串行为。单字符串、无返回值的形状及长度边界参考[接口文档](https://wofsauge.github.io/IsaacDocs/rep/Isaac.html#debugstring)，支持的字节捕获与返回值另用 CLI 核对。失败后通过初始化及已接受历史重建，未提交的日志、配置和绘制不保留。错误诊断只保留最后一次日志尝试和总尝试数；它是诊断，不是已经提交的日志。

## 重复性与历史失败

第一份清单运行到第 3 项时，测试器错误地在末尾状态步骤检查第 0 步的返回值。实际 Lua 返回 integer 0，符合无返回值调用的计数预期。V2 清单只修正检查位置，保留原源码和预期数值，原失败报告未删除。

随后补齐缺少服务配置的拒绝，以及复制前的超长消息/字段检查，V3 增加 3 项入口边界案例。完整回归中，旧混合 GC 案例出现弱引用扫描次数相差 1 的间歇失败；画面、配置、世界及活跃状态相同。24 次短测覆盖已封存值对象版本和新服务版本，新版本复现 1242/1243 两种扫描次数。

因此 ABI 从 `-1` 更新为 `-2`：`value_status` 只返回活跃、创建、退休、固定引用和数值模型状态；扫描次数、峰值、字段读写次数仍完整保留在顶层成本统计，不混入可重放状态。没有改动世界、绘制、配置、变量版本或权威证据的比较。原失败、对应二进制及源码快照保留，随后另做 12 次短测比较严格状态和普通输出。成本计数没有被改成固定值。
