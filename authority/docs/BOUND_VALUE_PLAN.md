# Observed value/version bindings

Continue the immutable compact candidate in a separate x86 runtime, `ia-lua533-bound-values-1`. Preserve old binaries, source, manifests and results. Reuse the fixed research Lua library for capture and the original stock Lua library for independent scalar evaluation. No game, original mod edits, full tracer or resource copies.

1. Observe supported GETUPVAL/GETTABUP/GETTABLE operations at their actual live instruction, recording the value, field/cell version, table lifetime, key and activation. Only direct table results are bindable; metatable fallbacks remain unsupported. Observe function parameters at entry, without claiming caller provenance.
2. Use call/return hooks only in optional binding captures. Retain the latest observation at each live source position, plus immutable references held by actual drawing sites. Drop unconsumed returned frames, prune error-unwound frames, and reject ambiguous repeated positions or unsupported Lua tail activations. No initialization provenance or per-instruction history.
3. Bind backwards recipes to those observations, then use stock Lua scalar operators to check raw text bytes and integer coordinates against the real model draw. Check namespace, key, table selector and read time; never reread final configuration or invent unknown native results.
4. Validate before/after writes, A→B→A, aliases, cached values/functions, helper parameters, raw strings and scalar operations. Keep call results, captured-local writes, branches, loops and C trampolines unresolved until their required summaries exist. Test corruption, caps, rollback and release using bounded CLI batches; rerun preserved gates.

The native capture and verifier each have a 5-second process timeout. Capture + recipe analysis + verification must fit the existing 10,000,000 work cap. Source records have a 256-KiB serialized payload cap and 4096 live-record cap; live Lua frames are capped at 32. Existing prototype/draw/read caps remain unchanged. Reports distinguish observed-frame equality from origin/authority correctness. Cache reuse, authority projection, game HUD replay and arbitrary-mod compatibility remain false.
