# 暂停快照与动画时钟结果

2026-10-17。命令行原型已补齐显式暂停查询，并能推进 EID 原始源码播放的 Arrow 循环动画。完整回调继续推进到了 `SFXManager` 和 `GetPlayerType`，尚未通过真实菜单、完整 HUD 或原生画面验收。

## 实现与边界

新增私有 ABI `ia-lua533-ui-flow-1`，入口 `--ui-flow-suite`。字体捕获候选及冻结模组源码均保持原样。

`Game.IsPaused` 读取权威场景中的显式布尔值，记录该字段的值和版本。缺少字段、非布尔值、错误参数均拒绝；不会根据帧号或当前界面推测暂停状态。主客查询读取同一权威值，个人配置与私有动画仍独立。

动画时钟依据原始 ANM2 的 FrameNum、Loop 以及显式 Play 建立。冻结了现有七个资源、81 个动画的元数据；打包资源只验证已有的有界区间，没有重新哈希整包或复制图片。循环 Update 更新固定的时钟和帧版本，不逐次追加操作。资源重载、GC 和 SetFrame 会使旧播放证明失效。

**这里只验证了模型规则，没有测得新的 J460 原生 Update 对照。** 非循环动画的终止边界、播放标志及 SetFrame 后的推进仍明确拒绝，不返回推测的结果。循环的模型推进不能替代后续原生行为及画面核对。当前持续存储结论只针对 Update 时钟，不代表会话历史或所有精灵操作都已具备长期回收能力。

## 检查结果

- 36 项新检查两轮通过：21 项功能/恢复、15 项明确拒绝。覆盖暂停跨角色读取、字段失效、A→B→A、循环跨界、缓存函数、非强制 Play、强制重播、独立配置、主机一次奖励、保存重建、失败恢复和 GC。
- 连续 10,000 次 Update 后，仍只有一个时钟和原来的两条 Load/Play 操作；帧为 16，符合 48 帧循环。该样本约 0.055 秒、150,907 工作单位，结束时私有提交约 4.79 MiB。这是短模型检查，不是 10,000 个游戏帧或长期泄漏验收。
- 原 48 项字体检查保持通过。原 37 项对象与场景、41 项精灵检查的功能状态、返回、错误和绘制结果相同。
- 上述对象回归有一次严格元数据比较不相同：`bounded-gc-churn` 的显式 GC 堆采样总量和对应预付费用不同，回收数量和对象生命周期相同。原始失败保留，`ui-flow-legacy-regressions-v1/review.json` 单独排除这两个分配器相关观测量后逐项核对其余结果，没有覆盖原判定。
- 开启新能力后，未经修改的 EID 及组合环境中的 `renderString` 再次产出准确的原始文字、资源、颜色、位置、缩放和绘制设置。仍未运行真实游戏绘制。

所有子进程保持 1000 万工作单位、5 秒和 1 GiB 配额；没有全量追踪、无上限长跑或个人存档写入。首轮新检查有一个诊断预期字符串写错，原始 35 项清单和失败报告及驱动源码均保留；修订清单另存为 `ui_flow_v2.json`，未修改其 Lua 源码。
